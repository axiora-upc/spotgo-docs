# SpotGo - Documentación del Proyecto

Repositorio de documentación del proyecto **SpotGo**, desarrollado por la startup **Axiora** para el curso **Desarrollo de Aplicaciones Open Source (UPC)**.

## Resumen

SpotGo propone una solución para mejorar la gestión de estacionamientos con alta demanda, enfocándose en:

- Organización de espacios por tipo de usuario.
- Reducción del tiempo de búsqueda de estacionamiento.
- Mejor experiencia para conductores y personal administrativo.

Este repositorio contiene el informe completo del trabajo final, incluyendo investigación, análisis, diseño, arquitectura, implementación y evidencia de sprint.
